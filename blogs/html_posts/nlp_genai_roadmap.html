NLP & GenAI Roadmap

Thirteen phases from tokenization to self-improving agents, ending in a capstone that uses nearly every topic. The spine is transformers → fine-tuning → quantization → retrieval → routing → agent memory. Effort assumes an existing LLMOps, RAG and agentic-infrastructure background, so retrieval and evaluation rate lighter than the model internals.

Priority = interview and debate relevance. Amber-edged phases are Critical.

Capstone

One project that exercises fine-tuning, quantization, hybrid retrieval, routing, memory and a self-improvement loop end to end.
